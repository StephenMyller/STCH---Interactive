
\subsection{Axiom of Class Formation}

\nbgpara{1}{}
Extensionality establishes that a membership specification
can determine at most one class. It does not, however,
guarantee that any such class exists. The Axiom of Class
Formation addresses this question by guaranteeing the
existence of classes specified by certain membership
conditions.

\nbgpara{2}{}
We consider specifications of the form
\[
\forall_S\xi
\bigl(\xi\in\eta\leftrightarrow\varphi\bigr),
\]
where \(\varphi\) determines which sets belong to
\(\eta\). The essential restriction on \(\varphi\) is
\emph{predicativity}: defining conditions may quantify
over sets, but unrestricted quantification over classes
is not permitted.

\begin{definition}[Predicative Membership Conditions]
A membership condition is \emph{predicative} if it belongs
to the permitted predicative syntax, possibly after the
application of justified predicative reductions.
\end{definition}

\nbgpara{2.1}{}
For example, the conditions
\[
\xi\notin A
\qquad\text{and}\qquad
\forall_S y\,(y\in\xi\to y\in A)
\]
are predicative. The class \(A\) occurs as a
\emph{parameter}: it may be any class, including a proper
class, but is not itself quantified over.

By contrast,
\[
\forall B\,(\xi\in B\to B=A)
\]
is not directly admissible, since its unrestricted
quantifier ranges over all classes.

\nbgpara{2.2}{}
Defined notation requires some care. For example,
subclasshood is defined using unrestricted quantification,
but it admits the equivalent formulation
\[
A\subseteq B
\quad\leftrightarrow\quad
\forall_S x\,(x\in A\to x\in B),
\]
because only sets can belong to classes.
Consequently, subclasshood may occur in predicative
conditions.

The distinction between formulas admitted directly by
Class Formation and those admitted through justified
predicative reductions is developed precisely in
\hyperref[sec:technical-class-formation]
{Appendix~\ref*{sec:technical-class-formation}}.

\nbgpara{3}{}
We can now state our second set-theoretic axiom.

\begin{axiom}[\textbf{\hspace{-0.12cm}Class Formation (Schema)}]
\label{ax:class-formation}
Let \(\varphi\) be a core predicative membership condition.
Let \(\xi\) and \(\eta\) be distinct variables, and suppose
that \(\eta\) does not occur free in \(\varphi\). Then
\[
\exists\eta\,
\forall_S\xi
\bigl(
\xi\in\eta
\leftrightarrow
\varphi
\bigr).
\]
\end{axiom}

Thus, every condition admitted by the schema determines
a class whose members are precisely the sets satisfying
that condition.

Notice that the existential quantifier is unrestricted:
the class whose existence is asserted need not itself
be a set. Only the universal quantifier is restricted,
since classes can have only sets as members.

\nbgpara{3.1}{}
The term \emph{schema} indicates that this is a family
of axioms, one for each core predicative condition.
Class Formation statements involving further justified
predicative notation are derived theorems rather than
additional axiom instances.

Since membership in a class implies sethood, a restricted
membership specification is equivalent to the corresponding
unrestricted specification with sethood explicitly included
in the condition. This follows from the rules of restricted
quantification and elementary propositional reasoning;
the equivalence is established formally in
Metatheorem~\ref{meta:restricted-unrestricted-class-formulation}.

\nbgpara{3.2}{}
In Gentzen derivations, a direct instance of Class
Formation may be introduced without premises:

\begin{prooftree}
    \AxiomC{}
    \RightLabel{\(\mathrm{A}_2\)}
    \UnaryInfC{
        \(\exists\eta\,
        \forall_S\xi
        \bigl(
        \xi\in\eta
        \leftrightarrow
        \varphi
        \bigr)\)
    }
\end{prooftree}

\nbgpara{4}{}
Combining Class Formation with the uniqueness of class
specifications established earlier yields the following
result.

\begin{proposition}[Existence and Uniqueness of Predicatively Specified Classes]
\label{prop:existence-uniqueness-class-formation}
Let \(\varphi(x)\) be a condition admitted directly
by the Class Formation Schema, and let \(A\) be a
variable that does not occur free in \(\varphi(x)\).
Then there exists exactly one class \(A\) satisfying
\[
\forall_S x
\bigl(x\in A\leftrightarrow\varphi(x)\bigr).
\]
\end{proposition}

\begin{proof}
Existence follows from the Axiom of Class Formation.
Uniqueness follows from
Proposition~\ref{prop:uniqueness-class-specification}.
Applying Unique Existence Introduction gives the result.

\begin{formalderivation}[0rem][prop:existence-uniqueness-class-formation]
\begin{prooftree}
    \AxiomC{}
    \RightLabel{\(\mathrm{A}_2\)}
    \UnaryInfC{
        \(\exists A\,\forall_S x
        (x\in A\leftrightarrow\varphi(x))\)
    }
%
    \AxiomC{}
    \RightLabel{P\ref{prop:uniqueness-class-specification}}
    \UnaryInfC{
        \(\Unique A\,\forall_S x
        (x\in A\leftrightarrow\varphi(x))\)
    }
%
    \RightLabel{\(\exists!\)-I}
    \BinaryInfC{
        \(\exists! A\,\forall_S x
        (x\in A\leftrightarrow\varphi(x))\)
    }
\end{prooftree}
\end{formalderivation}
\end{proof}

Predicativity restricts the conditions for which Class
Formation guarantees existence. It imposes no corresponding
restriction on uniqueness: Extensionality ensures that any
membership specification can be satisfied by at most one
class, whether or not its defining condition is predicative.
